**权威在这几处**（通用文件与 PDF）：

- **规范**：ISO 32000（PDF）—— 对象、字体、编码、内容流的语义。拿不准一段字节该怎么解、
  一个字体映射为什么错位，以它为准。
- **库的源码**：`PyMuPDF`（`fitz`）与 `pdfplumber` 装在本机 `.venv` 里；
  用 `run_command` 读它们的源码与 docstring，别凭记忆填参数名。
- **原始字节**：先把 `raw` / `bytes` 打出来看一眼再决定怎么解 ——
  猜解码方式一个个试，代价是时间。

本 skill 的写件改的是用户的文件；处理不了就明说，别交半成品。
