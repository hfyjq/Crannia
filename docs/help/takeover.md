接管把鼠标和键盘借给 Agent。它只在**桌面版**、并且当前对话处于**完全权限**时才可启用。这两条是并列的前提，缺一条按钮就是灰的，悬停会告诉你缺的是哪一条。

接管期间，Agent 可以看见窗口、点击、输入文字、按键和滚动，替你把界面操作做完。它不做后台操作：每一步都来自对话里的一条指令，发生在你能看见的桌面上。

## 启用之前你会看到什么

- 一条安全警告，说清「不要在 Agent 操作电脑期间干预输入」。
- 「启用」按钮有三秒倒计时，倒计时结束前按不动。
- 警告上有「我知道了」：勾上以后不再弹这条警告，但接管本身每次仍要你点按钮才开。

## 控制权在谁手里

- **同一时刻只有一条对话能接管**。第二条来要的时候会被拒绝，并说清是谁在用。不排队，也不抢占。
- **每个应用第一次被控制之前会问你**：允许（本次对话）、同意且永久批准、不允许。永久批准会写进设置页的「接管应用」名单，可以随时删。
- **一次观察对应一个动作**。从观察到点击之间窗口变了，这个动作直接失败，不会重试到别的窗口上。
- Agent 停止操作时，这一轮就结束；下一次动电脑会重新开始检测。

## 它够不到什么

- **按应用拒绝**：终端、登录与权限提升界面、密码管理器、系统安全设置。
- **按按键拒绝**：Windows 键、Ctrl+Alt+Del，以及急停键本身（Agent 按不出它）。
- **锁屏、或切到安全桌面**：直接停止。
- **前台校验**：每次输入之前都会确认目标仍是前台；目标窗口的权限比我们自己高时，会提前说「够不到」，不去试。
- 命中就拒绝；没命中不等于安全。

## 什么会让它停

- 你再点一次接管按钮。
- 物理按下 Esc。这是急停，任何时候都有效。
- 从托盘退出，或者把模式切换出完全权限。
- Agent 正在操作时，你用物理键盘、鼠标、滚轮或拖拽：立即退出接管。
- 打字下指令、打开目标应用这些不算干预。检测只在 Agent 真正开始操作那一刻开始，一轮结束后自动停止检测。

## 接管期间你一直看得见什么

桌面壳顶部有一条常驻横幅，写着接管正在进行、按 Esc 可以退出。它一直在最前面，不会被别的窗口盖住。

这也是接管只在桌面版可用的原因：浏览器里没有这条横幅，也就没有这道保证。

## 出问题时的确定结果

- **窗口变了、前台变了、元素找不到了**：动作失败并报给 Agent，不重试；由它重新观察再决定。
- **第二条对话要接管**：拒绝，并说清当前持有者。
- **框架重启或应用退出**：接管会随之结束，下次要重新开。
- **`/clear` 不会清掉接管**：它清的是一段对话的内容，不是「谁在拿着鼠标」。

## 相关设置

- **完全权限**（输入框的模式按钮）：接管的前提之一，只对当前对话生效。
- **接管应用**（设置 · 对话）：永久批准过的应用名单，可以随时删。
- **恢复安全提示**（设置 · 安全）：让「我知道了」失效，下次重新弹那条警告。
